# Painel Interativo

Projeto desenvolvido durante meus estudos de JavaScript.

## 💻 Sobre o projeto

Um painel de boas-vindas interativo que recebe o nome e a cor preferida do usuário e utiliza essas informações para personalizar a página.

## 🚀 Tecnologias utilizadas

- HTML5
- JavaScript

## 📚 Conceitos praticados

- `const`
- `prompt()`
- `document.querySelector()`
- `textContent`
- Template Literals
- Manipulação de estilos com `.style.color`

## ✨ Funcionalidades

- Solicita o nome do visitante
- Solicita uma cor em inglês
- Personaliza a mensagem de boas-vindas
- Atualiza o status do usuário
- Altera a cor do título conforme a escolha do visitante
